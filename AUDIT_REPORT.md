# Football Data Lab — Полный аудит кодовой базы (Ponytail Audit / Gemini 4 Argon)

**Дата аудита:** 2026-11-07  
**Статус:** все 19 пунктов исправлены (2026-11-09), `go build ./...` и `go test ./...` проходят. По п. 9 инлайн-клавиатура отключена; текстовая ссылка на Mini App в Rich Message не добавлена (в проекте нет подтверждённого типа блока для ссылок) — ссылка есть в подписи альбома.  
**Что делает этот репозиторий:**  
Платформа **Football Data Lab** загружает футбольную статистику и котировки из Sportmonks API в PostgreSQL, рассчитывает аналитику (таблицы, форму, xG, серии, экспрессы, футбольные аномалии), рендерит PNG-инфографику через Headless Chromium, публикует посты и дайджесты европейской прессы в Telegram-канал по расписанию и отдаёт JSON REST API для интерактивного Telegram Mini App.  
**Предполагаемая нагрузка:** фоновые крон-задачи и демоны на одном продакшен-сервере + сотни читателей Telegram-канала, одновременно открывающих Mini App в момент выхода поста.
